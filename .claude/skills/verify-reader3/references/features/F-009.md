# F-009 Paginated epub.js reader

Ledger row: [F-009](../../../../../docs/feature-ledger.md) (Summary table and the
`#### F-009 Paginated epub.js reader` section). Status: accepted.

## Sub-features

- Clicking a book card opens `/read/{book_id}/0`, paginated inside the epub.js iframe.
- `→` / `PageDown` and `←` / `PageUp` turn pages; `↓` / `↑` change section.
- The progress pill reads 「当前阅读至 N%」.
- The rail's Table of Contents button opens the chapter list with a "Search chapters..."
  filter.
- The back arrow returns to the library.
- `window.Reader3Epub.getDebugState()` returns `v: 1`, `ready: true` and the current
  `section.index`.

## How to get to it (user POV)

Library page → click the book card → the reader opens on the first section. Use the keyboard
to turn pages. Click the rail's TOC icon for the chapter list, and the back arrow (top left)
to go back.

## Driving it with control.py and $B

```bash
python3 .claude/skills/verify-reader3/scripts/control.py up --corpus smoke --epub ./some.epub
python3 .claude/skills/verify-reader3/scripts/control.py doctor
python3 .claude/skills/verify-reader3/scripts/control.py evidence start F-009
$B goto "$BASE_URL/"
$B wait '[data-testid="lib-main"]'
$B click '[data-testid="lib-book-card"][data-book-id="smoke_data"]'
python3 .claude/skills/verify-reader3/scripts/control.py reader state --wait 15
$B url
python3 .claude/skills/verify-reader3/scripts/control.py evidence add --browse-screenshot 01-reader-open
$B press ArrowDown
python3 .claude/skills/verify-reader3/scripts/control.py reader state
$B js 'document.querySelector("[data-testid=rd-page-indicator]").textContent'
$B click '[data-testid="rd-rail-toc"]'
$B wait '[data-testid="rd-toc-filter"]'
python3 .claude/skills/verify-reader3/scripts/control.py evidence add --browse-screenshot 02-toc
$B click 'a[title="Back to Library"]'
$B wait '[data-testid="lib-main"]'
python3 .claude/skills/verify-reader3/scripts/control.py evidence result PASS --note "open, keys, pill, TOC, back, debug state"
```

`BASE_URL` is `up`'s `data.base_url`. For page turns inside one section, open the real book's
card instead (its id is in `up`'s `data.books`), then `$B press PageDown` and compare
`progress.sectionPage` in two `control.py reader state` reads.

## Gotchas

- `smoke_data` has one page per chapter, so `→` / `PageDown` there changes section rather than
  page. Page turns need a real multi-page EPUB passed with `--epub`.
- The pill is per section (`progress.sectionPercent`): a one-page section reads 100%.
  `bookPercent` is always null today.
- The first-render `sectionPage.total` is stale until the next navigation (#63). Read it after
  one page turn.
- `/api/health` is up long before epub.js renders: always `reader state --wait` before reading
  or pressing keys.
- The click into the reader is the proof of "Click a book card"; do not `goto /read/...`.
